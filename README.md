# Sabi Study Circle

Act as a senior frontend developer and UI/UX designer. Build a visually polished, minimalistic, modern and fully responsive landing page for SabiTask, a student-powered academic support marketplace connecting university students with talented student experts (SabiExperts).

1. Technology Stack

Next.js (App Router)

React

Tailwind CSS

TypeScript

Lucide React for icons

Google Font: Raleway, implemented using next/font/google

Use clean, reusable components and maintainable code. Avoid unnecessary dependencies.

2. Brand Identity

Use the following brand colours consistently:

Primary Purple: #5936A8

Accent Orange: #FF9B38

Background: #F7F5FC

Text: #252238

White: #FFFFFF

Typography:

Use Raleway throughout the entire website.

Use bold and extra-bold weights for prominent headings.

Use regular and medium weights for paragraphs, navigation and buttons.

Design personality:

Youthful

Intelligent

Trustworthy

Collaborative

Modern and approachable

Purple should be the dominant brand colour. Use orange sparingly for secondary emphasis, highlights and selected interactive elements. Maintain sufficient colour contrast.

3. Website Structure

Build the landing page with these six sections, in this exact order:

SECTION 1: HERO

Create a clean, spacious hero section with all primary content aligned centrally.

Requirements:

Bold, prominent headline positioned in the middle.

Short supporting paragraph explaining what SabiTask does.

One clear primary CTA button.

Use a strong typographic hierarchy.

Keep the layout minimal with generous whitespace.

Use a subtle lavender background or a clean white background.

Add small decorative brand elements only if they improve the design.

Suggested copy:

Headline: Academic Support, Powered by Students.

Supporting text: Get the academic guidance you need from talented student experts. Learn better, grow together and make every academic challenge easier.

Primary CTA: Find a SabiExpert

The hero CTA should link directly to the Find a SabiExpert section. Reuse the same primary CTA wording and visual style wherever that action appears elsewhere on the page.

SECTION 2: SERVICES

Create a simple, attractive section introducing the types of academic support available on SabiTask.

Requirements:

Clear section heading and short introduction.

Display services in a clean responsive grid.

Use simple icons or subtle illustrations.

White cards with soft borders or very subtle shadows.

Rounded corners, consistent spacing and minimal decoration.

Each service should have a short description.

Suggested services:

Tutoring and Concept Explanation

Research and Project Guidance

Research Methodology Support

Data Analysis Guidance

Academic Mentorship

Study and Learning Support

Keep the cards visually balanced. Do not overload them with text.

SECTION 3: FIND A SABIEXPERT

Create a two-column feature section inspired by the attached hand-drawn reference sketch.

Layout:

Text and CTA on the left.

A large, attractive image or visual representing SabiExperts on the right.

On smaller screens, stack the content vertically, with text first and image second.

Content:

Heading: Find the Right SabiExpert for You.

Supporting text: Connect with talented students who can help you understand difficult concepts, improve your skills and navigate academic challenges with confidence.

Include three or four concise benefit points:

Find support that matches your academic needs.

Connect with talented and verified student experts.

Get guidance at student-friendly prices.

Learn at your own pace.

CTA button: Find a SabiExpert

The visual should communicate collaboration, peer learning and academic confidence. Use authentic-looking student imagery rather than generic corporate stock photography.

SECTION 4: BECOME A SABIEXPERT

Create a second two-column feature section, using the same visual style as the Find a SabiExpert section.

Important layout requirement:
Alternate the layout from the previous section.

Image on the left.

Text and CTA on the right.

On mobile, stack the content vertically, with text first and image second.

This section should feel like the natural counterpart to the previous section.

Content:

Heading: Turn Your Knowledge into Opportunity.

Supporting text: Are you good at explaining difficult concepts? Share your knowledge, support fellow students and earn by helping others learn.

Include concise benefits:

Earn from your academic strengths.

Build your reputation as a SabiExpert.

Help fellow students succeed.

Grow your skills and experience.

CTA button: Become a SabiExpert

The image should communicate confidence, mentorship, knowledge-sharing and student entrepreneurship.

SECTION 5: JOIN OUR WHATSAPP CHANNEL

Create a distinct, visually appealing CTA section encouraging students to join the SabiTask WhatsApp channel.

Requirements:

Clear headline.

One short supporting paragraph.

Prominent WhatsApp CTA button with a WhatsApp icon.

Use the primary purple brand colour with subtle accent elements.

Keep the section compact and visually focused.

Suggested copy:

Heading: Stay Connected with SabiTask.

Supporting text: Get updates, academic opportunities, learning resources and exciting announcements from the SabiTask community.

CTA: Join Our WhatsApp Channel

Use a configurable placeholder for the actual WhatsApp channel URL. Do not invent a URL.

SECTION 6: FOOTER

Create a minimal, well-organised footer.

Include:

SabiTask logo or text-based wordmark.

Short brand description.

Quick navigation links.

Find a SabiExpert link.

Become a SabiExpert link.

WhatsApp channel link.

Social media links using configurable placeholders.

Copyright notice.

Keep the footer clean, with a purple or dark charcoal background and readable white text.

4. Design and User Experience Requirements

Minimalist, modern and premium-looking visual design.

Generous whitespace and consistent section spacing.

Strong visual hierarchy.

Consistent button sizes, border radii and spacing.

Smooth scrolling for section navigation.

Subtle hover and focus states.

Lightweight transitions and restrained animations.

Avoid excessive gradients, floating elements, glassmorphism and unnecessary decorative effects.

Avoid overcrowded layouts and excessive text.

Use authentic student-focused imagery.

Ensure all buttons and navigation links have meaningful destinations.

Use a consistent maximum-width container throughout the page.

5. Responsive Design

The landing page must work beautifully across:

Desktop screens

Laptops

Tablets

Mobile phones

On mobile:

Use a clean, accessible navigation menu.

Stack two-column sections vertically.

Preserve the intended alternating desktop layouts.

Make CTA buttons easy to tap.

Prevent horizontal overflow.

Maintain comfortable text sizes and spacing.

6. Technical Requirements

Use Next.js App Router.

Use reusable React components for each section.

Use Tailwind CSS for styling.

Use semantic HTML elements.

Add accessible labels and meaningful image alt text.

Optimise images and loading performance.

Use next/image where appropriate.

Implement SEO metadata, including page title and description.

Ensure the layout is accessible by keyboard.

Use clean, organised and production-ready code.

Keep external URLs and social links configurable.

Suggested component structure:

Navbar

HeroSection

ServicesSection

FindExpertSection

BecomeExpertSection

WhatsAppCTASection

Footer

7. Expected Deliverables

Produce:

A complete, functional Next.js landing page.

Reusable React components for all six sections.

Responsive Tailwind CSS styling.

Raleway font integration.

Consistent application of the SabiTask brand colours.

Functional navigation and CTA links.

Placeholder configuration for WhatsApp and social media URLs.

Clean, readable and maintainable source code.

Final Design Direction

The finished page should feel like a modern student-focused technology startup, not a traditional school website.

Prioritise clarity, trust, simplicity and conversion.

A visitor should understand what SabiTask does within five seconds and immediately know how to either find a SabiExpert or become one.

Do not add extra sections beyond the six specified. Do not invent testimonials, statistics, student counts, ratings or claims that have not been provided.

Design quality benchmark: Clean typography, thoughtful spacing, strong CTAs, beautiful imagery and a seamless mobile experience.
